# jmpr

一个基于Java的多媒体播放器应用，支持本地文件播放和远程API媒体流播放。

## 功能特性
- 支持本地音频文件播放
- 支持通过API接口播放远程媒体文件
- 提供播放控制（播放/暂停/停止/上一曲/下一曲）
- 支持播放列表和播放历史记录
- 支持ID3信息显示
- 支持封面显示
- 支持播放速度调节
- 支持音量调节
- 支持进度拖动

## 技术栈
- Java 8+
- Swing GUI
- FFmpeg (可选)
- HTTP客户端用于API通信
- 嵌入式数据库管理API配置和播放历史

## 安装说明
1. 确保已安装Java 8或更高版本
2. 下载`mper.jar`文件
3. 双击运行jar文件或使用命令行运行：
   ```
   java -jar mper.jar
   ```

## 使用说明
1. 打开应用后，可以通过"文件"按钮选择本地媒体文件
2. 通过API管理功能添加远程媒体服务器
3. 在播放列表中选择媒体文件进行播放
4. 使用控制面板进行播放控制、调节音量和播放速度
5. 支持显示媒体文件的ID3信息和封面

## 开发构建
项目使用Maven进行构建：
1. 克隆仓库
2. 运行 `mvn clean package` 构建项目
3. 构建结果将生成在 `target/` 目录下

## 项目结构
- `src/main/java/yxs/a02/mper` - 主程序和核心功能
- `src/main/java/yxs/a02/mper/model` - 数据模型类
- `src/main/java/yxs/a02/mper/service` - 业务逻辑和服务
- `src/main/java/yxs/a02/mper/ui` - 用户界面组件
- `src/main/resources` - 资源文件
